# PK Launcher Theme Store

Official theme pack catalog for **PK Launcher** (`.pktheme` packs — full UI themes
with colors, custom CSS, wallpapers, **animated video backgrounds** and music).

- **Store index**: [`index.json`](https://raw.githubusercontent.com/MrRealORG/pk-themes/main/index.json)
- The launcher reads this URL by default (Theme Store → Source to change it).
- Packs download straight from `packs/` and install with one click.

## Make your own

Open PK Launcher → **Theme Store** page → **Theme Pack Maker**: pick colors, add a
wallpaper / animated video / music, hit **Save & Apply**, then **Export** to get a
`.pktheme` file you can share anywhere. Full format spec: [docs/THEME-PACKS.md](https://github.com/talha2223/PK-Launcher-/blob/main/docs/THEME-PACKS.md).

## Submitting a pack

Send your exported `.pktheme` to the PK Launcher maintainers (or open an issue with
a download link) — accepted packs get added to `index.json` + `packs/`.
